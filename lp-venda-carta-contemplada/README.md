# LP — Fivecred compra sua carta contemplada

Versão reformulada conforme briefing. Abra `../index.html` para acessar a página inicial, ou esta pasta em `/lp-venda-carta-contemplada/`. O arquivo `index.html` é a entrada principal; `dist/index.html` mantém o caminho anterior compatível.

CSS, JavaScript e ativos comuns ficam em `../shared`. O envio aguarda o webhook específico informado pelo responsável; o formulário exibe indisponibilidade até sua configuração. Os botões externos de WhatsApp pedem nome e e-mail antes de abrir a conversa, sem armazenamento local.
